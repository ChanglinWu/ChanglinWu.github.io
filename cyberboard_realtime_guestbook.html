Firebase 配置与 GitHub 部署说明

部署属于你自己的全球实时留言板

当前页面默认在预览环境下自动关联沙箱 Cloud 数据库。如果你要独立部署至自己的 GitHub Pages 仓库，请照以下步骤配置：

  1. 登录 Firebase Console 创建免费项目。
  2. 开启 Firestore Database 并在规则（Rules）中设置为可读写。
  3. 开启 Authentication 中的 匿名登录 (Anonymous) 权限。
  4. 在项目设置中复制 `firebaseConfig` 密钥对象。
